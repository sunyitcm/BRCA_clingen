变异证据审核

从判据强度回到指南原行、数据库记录和原始响应。每次联网复查独立留档。

本次基因　 　输入组装　
冻结快照

优先 VCF 位点：选原始组装，输入 chr-POS-REF-ALT，或粘贴单条 VCF 数据行。也支持指定转录本的 HGVS c.；每次一个 ALT。

只读文件不会自动联网。切换组装不会换算坐标。

同一审核台：开已有报告，或在本机查询

查看已有报告：下载 HTML，用浏览器双击打开。判据、版本和随页附带的原始数据都可离线查看。若下载后只显示预览，请保存文件再用 Safari、Firefox、Edge 或 Chrome 打开。

查新位点或复查：解压试用包，在该目录用已有 Miniforge 的 Python 3.10+ 执行 python start.py 即可。第一次查询会从 ClinGen 取回三份冻结工作簿并核对哈希。也可先运行 python start.py --prepare-rules。

浏览器打开的仍是这个页面。服务只监听本机（默认 127.0.0.1:8765）。两套组装共用一次安装。先选基因和原始组装，再输入 VCF 键或规范转录本的 c.，只在明确点查询时联系外站。坐标输入会核 REF，切换组装不会自动 lift。需要核重复区等价表示时，可在启动时提供对应组装的参考文件清单，见 README。

本地运行保留原始请求、响应、哈希及各次快照。没有数据库全量镜像；断网能回看，不能首次查询新变异。锁定附件明确赋码时会预选；点“校验、保存并计算”即另存本次结果。专家引用单列。规则更新须与取数更新分开审核。
