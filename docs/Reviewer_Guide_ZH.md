# 一个位点，先看结果，再看标准与出处

**rc8 快捷入口：** [首页操作说明](../README.md) · [文献与 LR](BRCA_Literature_and_Clinical_LR_ZH.md) · [API 和脚本说明](../METHODS_API_ZH.md)。在 PP4/BP5 下点“UCSC 本位点：逐条展开”，核对目标 ALT 后点击条目看分量；同一行点“下载 Parsons 2019 原始 Excel”可手查综合值（K 列），PP1/BS4 行指向共分离（F 列）。在“全文与人工阅读”读优先级和原文定位，这些操作不会改分。

**BRCA1 GN092 v1.2 与 BRCA2 GN097 v1.2 均启用 19 个主判据。** 致病侧 10 个：PVS1、PS1、PS3、PS4、PM2、PM3、PM5、PP1、PP3、PP4；良性侧 9 个：BA1、BS1、BS2、BS3、BS4、BP1、BP4、BP5、BP7。主判据与其可用强度分别管理。界面和报告 JSON 的逐判据表只列这 19 项，未取得原始资料时写明未取得；未勾选不等于不满足。默认展开本次有关的项，其余可随时展开。用户本机生成的原始快照不删减，故原站原文中可能提到其他代码。

**怎样手工补入？** 进入本机「查询」→ 展开其余判据 → 在自己有位点证据的行勾「计入」→ 选择该条实际强度 → 点「校验、保存并计算」。只有一档时已替你带出；多档没有默认最高档。无需填写理由、审核人或编号，一条公共备注完全选填。未勾选不代表阴性，保存会生成一条新修订。只读快照及双击打开的离线 HTML 只显示已保存的勾选，不能写回。

**怎样看中文和原文？** 以 PVS1 为例：先看功能丧失机制及变异类型，再依表 4、附录 D 确定档位；只测 mRNA 的实验另走图 1B 的 PVS1（RNA）分支。在每一行「逐档条文、英文与出处」可以读该基因各档的中文释义，看到所对应的官方 JSON 字段。中文为本项目转述，非官方译本。点 ClinGen 链接可核对英文网页；也可以下载该行所列的官方 JSON，点「对照此条英文」选择该文件，在浏览器本机核验 SHA-256 后显示逐档英文。只需选一次，同一页面上本基因其他行也可对照，不上传文件。命令行也可以执行 `python3 verify_guidance.py BRCA2 GN097_1.2.0.json --code PVS1 --strength Strong`；先核完整文件和该基因全部字段，再输出指定条文。

**怎样认来源？** 附件/本地阈值、引用专家、手工补入分开列在「已保存的所选证据」，每个代码最多计一次。手工补入表示解读员自有资料满足该档，不表示接口取得这些资料；指南文本和分值阈值本身不能证明位点满足。只有可以合并时才列总分；方向冲突或可能重叠会暂缓合计，BA1 不折算数值。重新打开可复核、改档或撤回，旧版本仍可读。不要为了复现测试结果给真实位点勾选没有依据的判据。

以包内固定的 GRCh38 BRCA2 c.9217G>T（CA10579818）教学快照为例；这些不是对当前数据库的实时断言：

| 判据 | 本次检索结果 | 程序怎样处理 |
|---|---|---|
| PS3 Strong | 已由冻结工作簿核准 Table 9 第 4682 行，D/E 明确为 PS3 / Strong。 | 自动预选。核 A/B 基因和 c.、转录本、D/E、工作簿哈希，遇相反推荐或歧义不自动使用。论文条数不计分。 |
| PP3 Supporting | 来自 LDH 的 BRCA Exchange noAF 分值 0.34。VEP 转录本 p.Asp3073 在 BRCA2 功能域内，域内错义阈值 ≥0.30。 | 自动预选蛋白分支一次；不另加 BP4 或 SpliceAI 分。BRCA1 的同一分支阈值是 ≥0.28。 |
| PM2 Supporting | 本次 LDH 没有该等位的 v4.1 外显子实体。eRepo 专家个案记载 v4.1 未见，>90% 样本深度 ≥25×。 | 默认不计；可勾「引用专家」。本地没有据此重算 PM2。若有规范两套非癌队列的等位计数、覆盖、质量和适用人群，Python 才能按冻结规范预选。 |
| PP4 Supporting | eRepo 记载综合 LR 3.57，由家族史贡献，位于 Supporting 区间 [2.08, 4.3)。 | 可一键引用这条专家记录；没有用原始家系数据重算 LR，也不转为 PP1。 |

**用法。** 在「查询」页选教学快照或联网查询的结果，勾选／取消即可保存。来源明确的附件或本地 Python 求值预选；仅能引用专家的项起初不选。无需键入审核人、理由、出处或独立编号。一次保存可不选任何项，也可只写一条选填备注。修订留存原查询哈希、来源、代码、实际强度、出处、UTC 与父版本；相同判据只能出现一次。切换页签不会保存。

**读数。** 此例按初始选择保存为 +5（PS3 +4、PP3 +1）。再选 PM2、PP4 得到 +7（附件／本地规则 +5；引用专家 +2）。“Likely pathogenic”是这组选中证据按同方向组合表所得的提示；不等于本地已独立得到四条证据或已签署分类。方向冲突、家系／似然比重叠等不能放心合并时不显示合计或分类提示；BA1 单列，不折算成分数。专家原判与新旧库差异始终能在同一页查阅。PS3 的不同来源可能涉及不同实验，保留原文，不能因此重复计 PS3。

**版本与出处。** 点「逐档条文、英文与出处」看本行的判读标准、指南链接、附件物理行、专家原文及报告字段。「原始数据」可以打开和下载原响应；教学摘录不内嵌完整外部响应。「各库版本与差异」区分取数时间和数据发布日期。4 条 LR 条文中明确写出的条件性 Very Strong 仍保存在对应行；不会添加规范不允许的强度。简版可选择已核准专家个案中的该档，不会声称从家系原始材料独立验证。完整来源与强度映射见原始报告和规范。

**可选：接入实验室已有的人群取证结果。** 默认查询不会下载 gnomAD 两套全库，也不把 eRepo 摘要当作本地计数。已有独立核准的数据可用 `python3 start.py --population-file population.json`，在一次新查询中仅选取完全匹配 CA、基因、版本化 c. 的记录。以下是字段骨架，不包含可用于计分的实际计数。两行分别提供两队列，不填值不采纳；文件内容留本机，报告保存本次匹配部分、文件哈希和出处。非本库覆盖的资源不得填入。

PM2 的本版自动分支仅处理 SNV；两套合格非癌子集中均无 ALT（AC=0）、AN>0，均有区域平均深度 ≥25×、实际出处、适用人群与质量核准。查无实体、HTTP 失败、仅一个队列或用 v4.1 替代均不满足本分支。该分支还要求提供 non_founder 和 outbred；它们并非同一个字段。source_ref 可为可定位的 HTTPS 链接或去标识的 LOCAL:记录#位置。此文件是用户提供的取证数据，程序核对字段与阈值，不验证操作者对外部队列的真实性。

**报告合同。** `criteria_table.rows[].brief` 的 result、standard、option、default_selected 与 HTML 同源。保存后的 `review_result.local_sources`、`quoted_sources`、`manual_sources` 分开，`selected_combination` 只指所选组合。`classification_local` 始终为空，快速模式不生成临床签发。原取数报告、每次保存的 report.json / report.html 与 review.json 分开保留。快照只读，无须安装；可写操作仅在本机服务。

官方来源：[BRCA1 GN092](https://cspec.genome.network/cspec/ui/svi/doc/GN092?version=1.2)、[BRCA2 GN097](https://cspec.genome.network/cspec/ui/svi/doc/GN097?version=1.2)、[本例 eRepo](https://erepo.clinicalgenome.org/evrepo/ui/classification/237f2389-fa0c-4474-9f7a-50a8f9a3542d)。

**新输入未通过身份核对时：** 先确认原 VCF 的组装。17-POS-REF-ALT 与 chr17-POS-REF-ALT 的写法都可用。参考接口报错时保留失败快照，不会换组装或评分；稍后在原组装重查，或明确核对 CAR 的另一组装表示后在该组装单独查询。


## 取数状态和原始组装

坐标输入先核原组装。CAR 核准确切等位和规范转录本；原组装 VEP、REF 和 gnomAD 分别请求。Ensembl 参考不可用时可按版本化 RefSeq 染色体核 REF。若指定了本地 FASTA，以它为准。取得唯一 CAR 跨组装 SNV 表示时才按对应坐标查询另一组装的非癌队列；原 GRCh37 VEP 不可用时也可另查 GRCh38 VEP。两次请求分别留存。跨组装 indel 不用简单位移替代规范化。

| 页面用词 | 应怎样读 |
|---|---|
| 有实际观察 | 看数据集、组装、外显子或基因组、祖源、AC 和 AN；不同队列不相加。AF 是 AC/AN。 |
| 明确未见记录 | 指该接口对这个等位的明确答复；返回空基因组对象、无链接或无变异记录，都不能生成 AC=0 或覆盖深度。 |
| 未查成／未取得 | 原始收据可看 HTTP 状态、时间及哈希。不能判阴性。 |
| 不满足／分支不适用 | 指定分支与数值或前提不符；不自动计相反方向分。只有另一个良性判据本身满足才能计其分值。 |
| 待核，不计分 | 可保存和撤回；保留在页首清单和 JSON 的 pending_codes 中，不进入 met 或积分。 |

人群主行优先列指南规定的历史队列；其他实际计数在同一行展开。采用远交人群的正观察时只用已对账的 ALT、无过滤标记及明确的祖源子行，不用全队列的一个总数判定。FAF95 的祖源与数值可查时才比较 BS1/BA1 的数值门槛；核查深度、适用人群和创始效应前不会自动给分。阴性功能实验只有符合本基因 BS3 的校准实验和适用条件才是良性方向证据。

规范给定的阈值、专家明确采用或未采用的结论、本地重算和手工判定分开列明。未结构化的专家段落与工作簿行可展开对照，不从关键词或论文数推断分值。“没有全文”也不等于没有功能研究。


## 用一个公开位点走完「查询 → 核证 → 计分」

1. 在本机查询页先选基因与原始组装。优先用 VCF 样式，例如 BRCA2、GRCh38、`chr13-32380106-G-T`；也可粘贴一行空格或制表符分隔的 VCF 记录，只取 CHROM、POS、REF、ALT，忽略 ID、INFO 和样本列。也接受 `NM_000059.4:c.9217G>T`；BRCA1 用 `NM_007294.4:c.…`。不能从单独 p.、不带版本的 c. 或多个 ALT 推断唯一等位。请勿把整份 VCF 粘入单行输入框。
2. 阅读每个判据的 **本次判定 → 观察值及标准 → 来源**。查到位点不等于该条达标；只满足蛋白分支、不适用、证据不足、服务错误、专家引用分别标示。位点数据与规范条文是两种不同来源。如果 gnomAD 浏览器把某队列返回成 null，那一项计数未知；若 LDH v4.1 的同一组装、同一 ALT 实体明确给出 AC=0、AN 和 noVariant，则按该发布实体单列，不能据此自动给 PM2。同一实体从两个接口返回不要累计。
3. 优先显示有数据的判据；展开其余可见本基因共 19 条。每条均有「计入」。复核后勾选；有多档且须人工补证时选择强度；按「校验、保存并计算」。在页首可看每项正负分及来源，BA1 按独立规则处理。身份未过或规范人群已观察到 ALT 的 PM2 只保存待核；互斥或不能形成合法组合时看旁边提示。取消选择再保存会生成新修订，不覆盖旧记录。静态 HTML 只读。
4. 对账成功的 eRepo 才显示专家补充；没有个案不占用摘要，不会降低等级。详细的接口状态与原始响应仍可追查。已查询的位点事实尽量归到判据；尚未赋码的附件与 LDH 目录另列。没有下载的实体、未接入的预测、未获得的家系或患者资料都不能宣称已覆盖。
5. 证据页的「文献与人工复核」显示本次关联 PMID；完整页区分规范工作簿、匹配的专家个案、ClinVar 胚系提交引用与人工指定。不会把疾病概述或一般方法指南的书目当作位点证据。可直接打开 PMID，或用核酸及蛋白别名查 PubMed、以功能／RNA 词缩小结果，或查 PMC 可访问全文。题名、摘要与正文、补表要分开看；核对核酸 ALT、实验模型和对照、队列重叠及排除理由。点击「取正文」才联网；一次失败最多再试一次，取不到仍有官方人工链接。不以论文数量加分。

## 人群、电脑预测和共分离怎样区分

先看本次判定，再看数值、版次和适用机制。「不适用」是规范明确排除此事件，即使补齐了数据库也不改变；「未满足」是已有可评价的反证；「资料不足」是当前查询不能作答。三者都不会自动加分，都不是“变异为良性”。如果是可用的 SNV，仅变异端点未收录、空数组或 500 不能证明 PM2。需要规范两队列、远交人群、区域覆盖以及同一等位的有效证据。LDH 和 gnomAD 全队列显示相同计数时不要相加。

- **移码／提前终止**：首个改变的氨基酸不等于提前终止密码子，更不代表 NMD 已被实验确认。核 PVS1 的转录本、可挽救剪接、RNA 条件及表 4。对于可从明确 fsTer 和简单的编码区编辑换算的事件，单个外显子完全覆盖终止密码子时才列 Table 4 和 ST1 的行号。PM5_PTC 还依赖 PVS1；表中候选不是本地分类。
- **BayesDel noAF**：分数原样列在 PP3／BP4，允许 0 或负数，附记录版次；只在规范允许的蛋白分支比较。SpliceAI 是单独分支；只返回四个 Δ、未核掩蔽和运行设置时显示线索，不当成已独立重算。数据源的历史先验概率、后验概率也不等于本地积分。
- **PP1／BS4**：核查该等位的定量共分离 LR；没有数值时保留为空。来源可为精确匹配的专家个案、BRCA Exchange 的可追溯分离字段，或已发表的定量家系方法。查原文时核家庭成员、基因型、表型和是否重复；需要自行推导时采用附录 I 方法。PP4／BP5 查临床综合 LR。共分离或家族史若已进入综合值，同一资料不能作为两条独立证据。强度阈值只在条文中说明，不冒充实测值。
- **换组装和版本**：公共库历史行若存在不同染色体等冲突，列于“各库版本与差异”，不据该行换算或派生临床 LR。原始 LDH 实体和另经核验的 BRCA Exchange 历史行分别标版。服务失败、原字段占位或没有第二组装参考锚时保留原因。
